## ⚠️ Potential Issues & Recommendations

### Issue 1: **No Error Handling**

**Current Code:**
```c
HAL_I2C_Master_Transmit(&hi2c2, DEBUG_I2C_ADDR << 1, test_data, sizeof(test_data), 100);
```

**Problem:** If I2C2 has no slave (which is expected for logic analyzer), this will:
- Timeout after 100ms (blocking!)
- Return HAL_TIMEOUT or HAL_ERROR
- May cause 100ms delay during commit

**Recommended Fix:**
```c
static void Debug_SendTestPattern(void)
{
    uint8_t test_data[] = {0xAA, 0x55, 0x01, 0x02, 0x03};

    // Non-blocking: ignore errors since we're just probing the bus
    HAL_StatusTypeDef status = HAL_I2C_Master_Transmit(&hi2c2,
                                                        DEBUG_I2C_ADDR << 1,
                                                        test_data,
                                                        sizeof(test_data),
                                                        10);  // Shorter timeout

    // Optional: check status for debugging
    (void)status;  // Suppress unused warning
}
```

### Issue 2: **7-bit vs 8-bit Address Confusion**

**Current Code:**
```c
#define DEBUG_I2C_ADDR  0x60  // Dummy address for logic analyzer
HAL_I2C_Master_Transmit(&hi2c2, DEBUG_I2C_ADDR << 1, ...);
```

**Address on Wire:**
- DEBUG_I2C_ADDR = 0x60
- Shifted: 0x60 << 1 = 0xC0
- Wire format: `0xC0` (Write) or `0xC1` (Read)

**Logic Analyzer will see:**
```
START → 0xC0 (Address + Write bit) → ACK/NACK → DATA → STOP
```

**Is this correct?** ✅ Yes! HAL expects 7-bit address, function shifts it.

**Alternative addresses for testing:**
```c
// Common I2C addresses for logic analyzer testing
#define DEBUG_I2C_ADDR  0x50  // Typical EEPROM address (wire: 0xA0/0xA1)
#define DEBUG_I2C_ADDR  0x60  // Your current choice (wire: 0xC0/0xC1)
#define DEBUG_I2C_ADDR  0x77  // I2C scanner probe address (wire: 0xEE/0xEF)
```

### Issue 3: **Test Pattern is Only Sent Once Per Commit**

**Current Behavior:**
- Test pattern sent at start of commit (line 354)
- Actual EEPROM writes happen after
- Logic analyzer sees: test pattern → long gap → EEPROM writes on I2C1

**Better Approach for Debugging:**

```c
#ifdef DEBUG_I2C_MIRROR
/**
 * @brief Mirror EEPROM write to I2C2 for logic analyzer comparison
 */
static void Debug_MirrorWrite(uint16_t offset, const uint8_t *data, uint16_t len)
{
    // Protocol: Send offset (2 bytes) + data
    uint8_t header[2] = {(offset >> 8) & 0xFF, offset & 0xFF};

    // Send address
    HAL_I2C_Master_Transmit(&hi2c2, DEBUG_I2C_ADDR << 1, header, 2, 10);

    // Send data
    HAL_I2C_Master_Transmit(&hi2c2, DEBUG_I2C_ADDR << 1, (uint8_t*)data, len, 10);
}
#endif
```

Then in `RamDisk_CommitToEEPROM()`:
```c
// Write this cluster directly to EEPROM
EEPROM_Status status = EEPROM_WriteBuffer(eeprom_offset,
                                           &data_buffer[data_offset],
                                           bytes_to_write);

#ifdef DEBUG_I2C_MIRROR
// Mirror to I2C2 for debugging
Debug_MirrorWrite(eeprom_offset, &data_buffer[data_offset], bytes_to_write);
#endif

if (status != EEPROM_OK) {
    return false;
}
```

This way you can compare I2C1 (real EEPROM) vs I2C2 (debug mirror) on the logic analyzer!

### Issue 4: **External Pull-ups Required**

**I2C2 Configuration:**
```c
GPIO_InitStruct.Pull = GPIO_NOPULL;  // No internal pull-ups
```

**⚠️ IMPORTANT:** You **MUST** have external pull-up resistors on PB13 and PB14!

**Typical values:**
- **4.7kΩ** - Standard for 100kHz I2C
- **2.2kΩ** - For 400kHz Fast Mode
- **10kΩ** - Slower, but works for logic analyzer testing

**Without pull-ups:**
- SDA and SCL will float
- No communication will occur
- Logic analyzer will show garbage

**Hardware Setup:**
```
     +3.3V
       │
       ├─── 4.7kΩ ──┬─── PB13 (I2C2_SCL)
       │            │
       └─── 4.7kΩ ──┴─── PB14 (I2C2_SDA)
```

## 🔍 How to Verify with Logic Analyzer

### Setup

1. **Connect Logic Analyzer:**
   - CH0 → PB13 (I2C2_SCL)
   - CH1 → PB14 (I2C2_SDA)
   - GND → Board GND

2. **Add External Pull-ups:**
   - 4.7kΩ from PB13 to +3.3V
   - 4.7kΩ from PB14 to +3.3V

3. **Logic Analyzer Settings:**
   - Protocol: I2C
   - Sample Rate: ≥ 1MHz (10x I2C clock)
   - Trigger: SDA falling edge

### Expected I2C Traffic

When you press the commit button, you should see:

```
Transaction 1: Test Pattern
├─ START
├─ Address: 0xC0 (Write to 0x60)
├─ NACK (no slave present - this is OK!)
├─ Data: 0xAA
├─ NACK
├─ Data: 0x55
├─ NACK
├─ Data: 0x01
├─ NACK
├─ Data: 0x02
├─ NACK
├─ Data: 0x03
├─ NACK
└─ STOP
```

**Timing:**
- I2C Clock: ~100kHz (10μs period)
- Total transaction time: ~500μs
- Timeout if no ACK: up to 100ms

### Troubleshooting

| Issue | Cause | Fix |
|-------|-------|-----|
| No signal on analyzer | Pull-ups missing | Add 4.7kΩ resistors |
| Both lines always HIGH | Pull-ups OK, no traffic | Enable DEBUG_I2C_MIRROR |
| Both lines always LOW | Short circuit | Check wiring |
| Garbled data | Wrong sample rate | Increase to ≥1MHz |
| Transaction repeats | I2C bus error | Check pull-up values |

## ✅ Recommended Improvements

### 1. **Enhanced Debug Functions**

Add to `ram_disk.c`:

```c
#ifdef DEBUG_I2C_MIRROR

// Test pattern for bus verification
static void Debug_SendTestPattern(void)
{
    uint8_t test_data[] = {0xAA, 0x55, 0x01, 0x02, 0x03};
    HAL_I2C_Master_Transmit(&hi2c2, DEBUG_I2C_ADDR << 1,
                            test_data, sizeof(test_data), 10);
}

// Mirror individual write to I2C2
static void Debug_MirrorWrite(uint16_t offset, const uint8_t *data, uint16_t len)
{
    // Send offset as 2-byte header
    uint8_t header[2] = {(offset >> 8) & 0xFF, offset & 0xFF};
    HAL_I2C_Master_Transmit(&hi2c2, DEBUG_I2C_ADDR << 1, header, 2, 10);

    // Send actual data
    HAL_I2C_Master_Transmit(&hi2c2, DEBUG_I2C_ADDR << 1,
                            (uint8_t*)data, len, 10);
}

// Marker for logic analyzer trigger
static void Debug_SendMarker(uint8_t marker_id)
{
    uint8_t marker[] = {0xFF, marker_id, 0xFF};
    HAL_I2C_Master_Transmit(&hi2c2, DEBUG_I2C_ADDR << 1, marker, 3, 10);
}

#endif
```

### 2. **Usage in Commit Function**

```c
bool RamDisk_CommitToEEPROM(void)
{
    // ... file discovery code ...

#ifdef DEBUG_I2C_MIRROR
    Debug_SendMarker(0x01);  // START marker
    Debug_SendTestPattern(); // Verify bus is working
#endif

    // Write loop
    while (eeprom_offset < file_size && !fat12_is_eof(current_cluster)) {
        // Calculate write parameters...

        // Write to real EEPROM (I2C1)
        EEPROM_Status status = EEPROM_WriteBuffer(eeprom_offset,
                                                   &data_buffer[data_offset],
                                                   bytes_to_write);

#ifdef DEBUG_I2C_MIRROR
        // Mirror to debug I2C (I2C2)
        Debug_MirrorWrite(eeprom_offset,
                         &data_buffer[data_offset],
                         bytes_to_write);
#endif

        if (status != EEPROM_OK) {
#ifdef DEBUG_I2C_MIRROR
            Debug_SendMarker(0xFF);  // ERROR marker
#endif
            return false;
        }

        eeprom_offset += bytes_to_write;
        current_cluster = fat12_get_entry(current_cluster);
    }

#ifdef DEBUG_I2C_MIRROR
    Debug_SendMarker(0x02);  // SUCCESS marker
#endif

    return true;
}
```
